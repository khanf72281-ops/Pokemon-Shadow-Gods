# Pokémon: Shadow Gods

An advanced, multiverse-spanning Pokémon RPG Engine built with Python and JSON data structures. 

## 🌌 Project Overview
- **Title:** Pokémon: Shadow Gods
- **Scope:** Complete 9-Region Progression (Gen 1–9) leading into the singularity transit of **Universe 2 (Bharat Region)**.
- **Battle Innovations:**
  - **DNA Splice Ring:** Fuse two compatible Pokémon into tactical hybrid forms.
  - **8-Move Tactical Watch:** Expanded move slots for hybrid strategic combat.
  - **Triple Phenomena Protocol:** Allowed usage of up to 3 distinct regional phenomena per match.
  - **Singularity Boss Mechanic:** True damage execution ("The Eternal Void" 500 flat true damage).

## 📁 Repository Structure
- `pokemon_engine.py`: Turn calculations, hybrid battle engine, and boss phase logic.
- `story_progression.py`: Universe 1 narrative from Kanto to the Northern Championship & Prof. Oak trial.
- `time_incursion_engine.py`: Temporal decay, speed inversion, and anomaly handlers.
- `hisui_incursion_event.py`: Space-Time rift, Strong/Agile styles, and ancient adaptations.
- `*.json`: Data definitions for Pokédex, Phenomena rules, Gym leaders, Legendary locations, and wild encounters.

# 🌌 Pokémon: Shadow Gods (Multiverse Edition)

An offline, 60 FPS Action-RPG set in the **Bharat Region (Universe 2)** and **Original Multiverse (Universe 1)**.

### 🔥 Key Features
- **Real-Time Action Combat & Dodging:** Move freely, dodge Shadow Orbs, and unleash cooldown-based Soul/Dragon attacks.
- **Overworld Partner & Catching:** Walk with your Bharat Starter and throw Pokéballs directly in the wild.
- **Sacred Dargah Purification:** Pacify 10 Shadow Titans at Ajmer Sharif & Haji Ali Dargah.
- **The Eternal Void Raid:** Team up with 10 Fusion Legendaries, 10 Bharat Guardians, and Gen 1–9 Champions against a 1,000 HP Dragon/Soul Primordial Boss.
- **100% Offline & Mobile Optimized:** Built with touch controls and lightweight rendering for smooth gameplay.
